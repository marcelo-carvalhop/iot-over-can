# Primeiro commit

Nome do projeto:

```text
iot-over-can
```

Mensagem recomendada para o primeiro commit:

```text
chore: initial iot-over-can baseline
```

Comandos:

```bash
git init
git branch -M main
git add .
git commit -m "chore: initial iot-over-can baseline"
```

Para publicar no GitHub, depois de criar o repositório remoto:

```bash
git remote add origin git@github.com:<seu-usuario>/iot-over-can.git
git push -u origin main
```

Alternativa usando HTTPS:

```bash
git remote add origin https://github.com/<seu-usuario>/iot-over-can.git
git push -u origin main
```
